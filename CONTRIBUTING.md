# Contributing

Thanks for your interest in contributing to layer87-labs projects.

## How to Contribute

1. Fork the repository
2. Create a branch: `git checkout -b feat/your-feature`
3. Make your changes
4. Run tests and ensure everything passes
5. Open a Pull Request

## Branch Naming

- `feat/` — new features
- `fix/` — bug fixes
- `chore/` — maintenance, dependencies
- `docs/` — documentation only

## Commit Messages

We use [Conventional Commits](https://www.conventionalcommits.org/).

## Reporting Issues

Use the issue templates provided in each repository.

## Maintainer

These projects are maintained by [Layer87](https://layer87.de).
Community contributions are welcome and reviewed by the Layer87 team.
