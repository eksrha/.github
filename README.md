# .github

Default community health files for the [layer87-labs](https://github.com/layer87-labs) organization.

Files in this repository automatically apply to all repositories in the org
that do not have their own version. See [GitHub Docs](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for details.

## Contents

| File                                  | Purpose                                                |
| ------------------------------------- | ------------------------------------------------------ |
| `CODE_OF_CONDUCT.md`                  | Contributor Covenant 2.1 — conduct@layer87.de          |
| `CONTRIBUTING.md`                     | How to contribute to layer87-labs projects             |
| `SECURITY.md`                         | Vulnerability reporting — security@layer87.de          |
| `pull_request_template.md`            | Default PR template                                    |
| `ISSUE_TEMPLATE/bug_report.yaml`      | Bug report template                                    |
| `ISSUE_TEMPLATE/feature_request.yaml` | Feature request template                               |
| `profile/README.md`                   | Organization profile shown on layer87-labs GitHub page |

## Maintainer

[Layer87](https://layer87.de) — these files are maintained centrally.
To propose changes, open a PR in this repository.
