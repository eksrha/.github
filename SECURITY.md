# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues.

Report vulnerabilities via email: security@layer87.de

We aim to respond within 72 hours and will keep you informed
throughout the process.

## Scope

This policy applies to all projects under the
[layer87-labs](https://github.com/layer87-labs) organization.
